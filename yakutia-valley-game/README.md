# Yakutia Valley — игра на Godot 4

Маленькая ферма на якутском аласе: балаган с дерновой крышей, сэргэ, камелёк, ураса олонхосута, якутская лошадь, озеро с карасями и тайга с брусникой. Весь пиксель-арт оригинальный и сгенерирован скриптом `_source/` (16×16 предметы, 16×32 персонажи, палитры по 5 тонов, свет сверху-слева, цветной контур).

## Как запустить на компьютере (Windows / macOS / Linux)

1. **Скачай Godot 4.3 или новее** (обычную версию, *не .NET*): https://godotengine.org/download
   - Windows: распакуй zip, внутри `Godot_v4.x-stable_win64.exe` — установка не нужна.
   - macOS: перетащи `Godot.app` в «Программы».
   - Linux: распакуй, сделай файл исполняемым (`chmod +x Godot_v4*`).
2. **Скачай папку игры** `yakutia-valley-game` (из репозитория: *Code → Download ZIP*, затем распакуй).
3. **Открой проект:** запусти Godot → в менеджере проектов нажми **Import** (Импорт) → выбери файл `yakutia-valley-game/project.godot` → **Import & Edit**.
   При первом открытии Godot пару секунд импортирует картинки — это нормально.
4. **Запусти игру:** клавиша **F5** (или кнопка ▶ справа сверху).

Запуск без редактора из консоли (после того как проект хотя бы раз открыли в редакторе):

```
Godot_v4.3-stable_win64.exe --path путь\к\yakutia-valley-game
```

### Как сделать отдельный .exe

1. В Godot: **Editor → Manage Export Templates → Download and Install** (один раз).
2. **Project → Export → Add… → Windows Desktop** → **Export Project** → укажи имя `YakutiaValley.exe`.
3. Получится `.exe` (и `.pck` рядом, если не отмечено *Embed PCK*) — его можно запускать без Godot.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | ходить |
| Пробел, C, левая кнопка мыши | использовать предмет в руке (мотыга, лейка, удочка, семена) |
| E, X, правая кнопка мыши | говорить, гладить коня, собрать урожай/ягоды, открыть амбар/камелёк |
| F | съесть предмет из руки |
| 1–0, `-`, `=`, колесо мыши | выбрать слот |
| H | показать/скрыть подсказку |
| Esc | закрыть меню |

## Что есть в игре

- **Огород:** мотыгой рыхлишь траву → сажаешь семена (картофель 6 дней, ячмень 4, репа 3) → поливаешь лейкой каждый день. Растут только политые грядки. Мотыгой можно разбивать камни; изредка из мерзлоты выкапывается **бивень мамонта**.
- **Рыбалка:** встань лицом к озеру, закинь удочку, жди «!» и жми ещё раз — карась, чир или… льдина.
- **Тайга:** кусты брусники у кромки леса, плодоносят раз в 3 дня.
- **Конь у сэргэ:** погладь раз в день — получишь кумыс.
- **Камелёк** (готовка): строганина (чир), алаадьи (2 ячменя), кёрчэх (кумыс + 2 брусники), чорон с кумысом (2 кумыса).
- **Амбар:** продажа предмета из руки.
- **Олонхосут Бэргэн** у урасы: разговоры, магазин (семена, хомус, торбаса, якутский нож), подарки раз в день. Любит хомус, строганину и бивень мамонта.
- **День** длится ~14 минут (6:00–2:00), вечером темнеет. Спать — у двери балагана; сон сохраняет игру. Если не лечь до 2:00 — проснёшься уставшим и потеряешь 10% денег.

Сохранение: `user://yakutia_save.json` (Windows: `%APPDATA%\Godot\app_userdata\Yakutia Valley\`). Удали файл, чтобы начать заново.

## Перегенерация спрайтов

Нужен Python 3 и `pip install pillow numpy`:

```
cd yakutia-valley-game/_source
python build_assets.py
```

PNG появятся в `assets/`, превью — `_source/preview.png`. Все спрайты описаны в `_source/sprites.py`, движок светотени — `_source/pix.py` (палитры материалов в словаре `P`).

## Структура

```
project.godot        настройки (окно 480×270 ×3, пиксельный фильтр)
main.tscn            единственная сцена
scripts/main.gd      мир, игрок, NPC, лошадь, интерфейс, сохранение
scripts/data.gd      предметы, культуры, рецепты, магазин, реплики
assets/              спрайты
_source/             генератор спрайтов на Python
```
